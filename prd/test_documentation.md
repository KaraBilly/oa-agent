## 1. 测试概述

### 1.1 测试目标

验证 OA Agent 的意图识别功能是否满足需求规格说明书中的要求，确保：

- 意图识别准确率 > 80%
- 实体抽取准确率 > 75%
- 澄清机制正常工作
- 性能指标达标

### 1.2 测试范围

| 模块 | 测试内容 | 优先级 |
|-----|---------|--------|
| IntentionRecognizer | 意图识别 | P0 |
| IntentionRecognizer | 实体抽取 | P0 |
| IntentionRecognizer | 置信度计算 | P1 |
| IntentionRecognizer | 澄清判断 | P0 |
| ResponseGenerator | 响应生成 | P0 |
| CapabilityRegistry | 能力分级 | P1 |
| IntentionMetrics | 指标计算 | P1 |
| LangGraph Workflow | 状态图流转 | P0 |
| MockDataSource | Mock数据服务 | P0 |
| ModelRouter | 多模型支持 | P1 |

### 1.3 测试策略

```
┌─────────────────────────────────────────────────────────────┐
│                        测试策略                              │
├─────────────────────────────────────────────────────────────┤
│  单元测试 (Unit Tests)  →  集成测试 (Integration Tests)      │

│       ↓                            ↓                         │
```
